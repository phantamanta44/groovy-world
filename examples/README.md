# Groovy World Examples

This directory contains a few example scripts that demonstrate the use of Groovy World:

| Example                                        | Description                                                                                                      |
|------------------------------------------------|------------------------------------------------------------------------------------------------------------------|
| [`dungeon.groovy`](dungeon.groovy)             | Generates a dungeon-like structure with a mob spawner and loot chest.                                            |
| [`oil.groovy`](oil.groovy)                     | Generates BuildCraft-style oil wells with geysers reaching up to the surface.                                    |
| [`ore_indicator.groovy`](ore_indicator.groovy) | Generates big ore veins deep underground accompanied by flower patches on the surface indicating their location. |
| [`randomizer.groovy`](randomizer.groovy)       | Dynamically generates random ore veins for all modded ores found in the ore dictionary.                          |
| [`vanilla.groovy`](vanilla.groovy)             | Generates underground features in a configuration roughly approximating that of vanilla.                         |
